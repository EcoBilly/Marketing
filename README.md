# Marketing · 인스타그램 팔로우 관리

인스타그램 공식 "내 정보 다운로드" 데이터로 맞팔 여부와 팔로우 이력을 관리하는 웹 도구입니다.
인스타그램에 자동으로 요청을 보내지 않기 때문에 계정 제재 위험이 없습니다. 팔로우와 언팔은 직접 하시면 됩니다.

## 기능
- **맞팔 안 한 계정 찾기**: 팔로우한 지 N일(기본 14일)이 지났는데 맞팔하지 않은 계정 목록을 보여주고, 프로필 링크를 제공합니다.
- **재팔로우 방지**: 한 번이라도 팔로우했던 계정을 모두 기록합니다. 후보 목록을 붙여 넣으면 이미 팔로우했던 계정은 걸러냅니다.
- **유지 목록**: 지인처럼 맞팔이 아니어도 계속 팔로우할 계정은 언팔 목록에서 빠집니다.
- **이력 · 백업**: 브라우저에 저장되며, JSON 파일로 백업하고 복원할 수 있습니다.

## 사용법
1. `index.html`을 브라우저로 엽니다.
2. 인스타그램 앱 → 설정 → 계정 센터 → 내 정보 및 권한 → 내 정보 다운로드 → "팔로워 및 팔로잉", **JSON** 형식을 선택합니다.
3. 받은 zip 파일을 ① 탭에 넣습니다. 매주 새로 받아서 넣으면 맞팔 여부가 갱신되고 이력이 쌓입니다.

## 개발
```
node test/core.test.js
```
- `core.js`: 데이터 해석과 계산 로직 (브라우저와 Node에서 모두 동작)
- `app.js`: 화면 동작
