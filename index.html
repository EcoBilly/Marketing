Marketing · 팔로우 관리

인스타그램 공식 데이터로 맞팔 여부와 팔로우 이력을 관리합니다. 데이터는 이 브라우저에만 저장되고, 인스타그램에 자동 요청을 보내지 않습니다.

📋 맞팔 늘리기 작업 순서

팔로우와 언팔은 모두 인스타그램에서 직접 합니다. 이 페이지는 "누구를 언팔할지, 누구를 다시 팔로우하면 안 되는지"를 알려주는 역할입니다.

🟢 매일: 팔로우하기

  1. 인스타에서 다이버들이 모이는 계정에 들어갑니다. 예: 다이빙 장비 브랜드, 다이빙 매거진, 해외 다이빙 리조트, 제주 여행 계정
  2. 그 계정의 팔로워 목록을 엽니다. 그 계정을 팔로우하는 사람들이 다이버이고, 우리가 찾는 타깃입니다.
  3. 프로필 사진이 있고 최근 게시물이 있는 실제 사람 계정만 골라 팔로우합니다. 업체, 광고, 비공개 빈 계정은 맞팔률이 낮으니 건너뜁니다.
  4. 헷갈리는 계정은 팔로우 전에 이 페이지의 ④ 이력 · 백업 탭 검색창에 아이디를 넣어 봅니다. "언팔"로 나오면 예전에 팔로우했다가 정리한 사람이니 누르지 마세요.
  5. 팔로우한 뒤 게시물 1~2개에 좋아요를 눌러 주면 맞팔 확률이 올라갑니다.

🔵 일주일에 한 번: 데이터 새로 넣기

  1. 인스타 → 설정 검색창에 다운로드 → 내 정보 다운로드
  2. 내 계정 선택 → 일부 정보 → 팔로워 및 팔로잉만 체크
  3. 기기에 다운로드 → 기간 전체 기간, 형식 JSON → 파일 만들기
  4. 알림이 오면 zip 파일을 받아 이 페이지 ① 데이터 불러오기에 넣습니다.

🔴 데이터 넣은 뒤: 맞팔 안 한 사람 언팔하기

  1. ② 맞팔 안 한 계정 탭을 엽니다. 팔로우한 지 14일이 지났는데 맞팔하지 않은 사람이 나옵니다.
  2. 아이디를 누르면 인스타 프로필이 열립니다. 팔로잉 → 팔로우 취소
  3. 뒤로 가기로 돌아와 다음 사람을 누릅니다.
  4. 업계 지인이나 참고용 업체 계정처럼 계속 팔로우할 계정은 유지를 눌러 목록에서 빼 둡니다.
  5. "언팔 완료" 버튼은 안 눌러도 됩니다. 다음 주에 데이터를 넣으면 자동으로 정리됩니다. 목록에서 바로 지우고 싶을 때만 누르세요.

⚠️ 계정 안전 수칙

  • 천천히, 나눠서. 손으로 해도 짧은 시간에 팔로우나 언팔을 많이 하면 인스타가 막습니다. 처음엔 하루 팔로우 20~30명, 언팔 20~30명 정도로 시작하고, 한 번에 몰아서 하지 말고 오전과 저녁처럼 나눠서 하세요. 인스타가 정확한 기준을 공개하지 않으니 넉넉하게 잡는 게 안전합니다.
  • "작업이 차단되었습니다" 같은 메시지가 뜨면 바로 멈추고 1~2일 동안 팔로우와 언팔을 쉬세요. 계속하면 차단 기간이 길어집니다.
  • 팔로우와 언팔을 같은 날 같은 사람에게 반복하지 마세요.
  • 자동 클릭 프로그램이나 AI 브라우저는 쓰지 마세요. 계정 정지 위험이 큽니다.
  • 이 페이지 기록은 지금 브라우저에만 저장됩니다. 가끔 ④ 탭 → 백업 파일 저장을 해 두세요.

💡 맞팔을 더 잘 받는 팁

  • 내 프로필이 먼저 매력적이어야 맞팔해 줍니다. 프로필 사진, 한 줄 소개(제주 스쿠버·프리다이빙·호핑투어·해녀체험), 고정 게시물 3개를 정리해 두세요.
  • 팔로우 작업하는 기간에는 릴스나 게시물을 꾸준히 올리세요. 들어와 본 사람이 볼 게 있어야 맞팔합니다.

인스타그램 데이터 불러오기

  1. 인스타그램 앱 → 설정 → 계정 센터 → 내 정보 및 권한 → 내 정보 다운로드
  2. "일부 정보" → 팔로워 및 팔로잉 선택, 형식은 JSON, 기간은 전체 기간
  3. 받은 zip 파일(또는 안의 json 파일들)을 아래에 넣으세요.

정기적으로(예: 매주) 새로 다운로드해서 불러오면 이력이 계속 쌓입니다. 이전 기록은 지워지지 않습니다.

맞팔 안 한 계정

팔로우한 지 일 이상 지났고 맞팔하지 않은 계정

0명 선택

계정 이름을 눌러 인스타그램에서 직접 언팔한 뒤 체크하고 언팔 완료를 누르세요. 언팔 완료한 계정은 이력에 남아 ③ 탭에서 "예전에 팔로우했던 계정"으로 걸러집니다. 지인처럼 맞팔이 아니어도 계속 팔로우할 계정은 유지를 누르면 목록에서 빠집니다.
실수로 언팔 완료를 눌렀어도 괜찮습니다. 다음에 데이터를 새로 불러올 때 아직 팔로우 중인 계정은 자동으로 "팔로잉"으로 바로잡힙니다.

팔로우 후보 검사

키워드로 찾은 계정 아이디나 프로필 링크를 붙여 넣으세요 (줄바꿈·쉼표·공백으로 구분). 한 번이라도 팔로우했던 계정은 걸러냅니다.

이력 · 백업

브라우저 데이터를 지우면 이력도 사라집니다. 가끔 백업 파일을 저장해 두세요.
